# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as
its code of conduct. The full text is published at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
and applies to every contribution surface for this repository:
issues, pull requests, discussions, the project's GitHub
organisation, and any out-of-band communication that references
the project.

Astraudit is a small, hobby-scale open-source project. The point
of adopting a recognised standard rather than writing our own is
that the rules and consequences are well-understood, vendor-neutral,
and consistent across the wider open-source ecosystem.

## Reporting

If you experience or witness behaviour that violates the
Contributor Covenant in any Astraudit space, please report it
through one of these channels:

- **GitHub Security Advisories** — open a private advisory at
  <https://github.com/BEKO2210/astraudit/security/advisories/new>.
  This routes the report directly to the maintainer and stays
  private.
- **Email** — write to `conduct@beko2210.dev`. Reports are
  acknowledged within 72 hours.

When you report, include:

- A short description of what happened.
- Where it happened (issue / PR URL, commit, comment thread).
- Whether you'd like to remain anonymous.

## Enforcement

The maintainer is responsible for clarifying and enforcing the
standard, and will follow the Contributor Covenant's
[Enforcement Ladder](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction → warning → temporary ban → permanent ban, scaled to
the impact and pattern of the behaviour.

## Scope

The Code of Conduct applies inside all official Astraudit project
spaces and to anyone who is publicly representing the project —
for example, by using an official email address, posting from an
official social media account, or speaking on Astraudit's behalf
at an online or offline event.
